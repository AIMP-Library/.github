## Core AIMP Features

- **A Playlist of Files:** Add tracks from a folder you may play. The list is pointers, not a store that supplies the music.
- **Playback Controls:** Play, pause, and skip inside that list.
- **Tags You Can Read:** See the title already written in the file. Changing a tag is a write. Do it on a copy if the file is the only one.
- **A Library of What You Added:** It does not fill itself from a shop or from other people's collections.

---

## About AIMP

AIMP is an audio player for files on your PC. Rips you were allowed to make from discs you own, purchases you downloaded from the seller, and recordings you made are the content. It is not a way to pull a streaming catalog offline, and a playlist is not a license.

Point it at one folder first. A library of every drive on the computer will include folders you did not mean to index. If a track is silent, check the file in another player before you blame the install. A corrupt download from a shop is fixed by downloading it again from that shop, not by hunting a different copy.

Volume and output device are the usual reasons a new install seems mute. Set those before you reinstall.

## Tool Benefits

- **Your Folder:** Playback follows files you placed on disk.
- **A Simple List:** You can hear an album without building a video project.
- **Tags Left Alone:** Listening does not rewrite the file unless you edit tags on purpose.

## Getting Started with AIMP

Prerequisites: A folder of audio you are allowed to play.

1. **Add That Folder:** Do not scan the whole PC.
2. **Play One Track:** Confirm sound from the device you expect.
3. **Build a Short List:** An album or a set you will actually finish.
4. **Close:** Leave tag editing for a copy if you are not sure the write is harmless.

---

## Professional & Personal Use Cases

- **A Desk Playlist:** Files you bought or recorded, played while you work.
- **An Album Check:** Hear a set you just copied from a disc you own.
- **A Shared PC:** Do not index another user's music folder.
- **A Mute Install:** Fix the output device before you look for a new copy of the songs.
